# Istiyak Hossain Ishan

**AI Engineer & Multilingual NLP Researcher**  
Research Engineer Intern @ AIMS Lab (IRIIC, UIU) · B.Sc. in Data Science @ United International University

I build production-grade retrieval-augmented generation (RAG) systems, asynchronous LLM evaluation harnesses, and parameter-efficient fine-tuning pipelines. My academic research explores **multilingual LLM robustness**, **safety alignment across asymmetric language pairs (English–Bengali)**, and **mechanistic interpretability** under domain adaptation and quantization.

### Core Focus & Stack

- **LLM & Retrieval Systems:** RAG Architectures, Qdrant, FastAPI, Celery, Async Evaluation Pipelines, Hallucination Detection
- **Model Adaptation & NLP:** PyTorch, Hugging Face Transformers, LoRA / QLoRA / PEFT, Sentence Transformers, Unigram & BPE Tokenizers
- **Full-Stack & MLOps:** TypeScript, Next.js, PostgreSQL, Redis, Docker, DVC, GitHub Actions CI/CD
